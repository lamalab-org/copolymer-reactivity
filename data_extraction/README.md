## Data Extraction

This directory collects every artefact related to gathering the copolymer data.
The actual pipeline lives in the modules under `src/copolextractor`; the
`obtain_data.py` script serves as a thin entry point.

- **Configuration:** All paths and thresholds are defined in
  `data_extraction/obtain_data.py` via the `ExtractionConfig` class. The default
  configuration mirrors the curated layout beneath `data_extraction/artifacts`.
- **Step selection:** `ExtractionSteps` lets you control which parts of the
  pipeline should run (for example, trigger only the LLM extraction without
  re-running Crossref). By default only the extraction and the CSV export run to
  avoid accidental API calls or downloads.
- **Working directories:** The script makes sure that every required folder
  exists before a step runs. Intermediate artefacts now accumulate under
  `data_extraction/artifacts`, while historic experiments are preserved in
  `data_extraction/archive`.

### Directory layout

- `artifacts/metadata/output`: Crossref results, download manifests, embedding
  caches and auxiliary metadata required by the pipeline.
- `artifacts/llm/processed_images`: Images rendered from PDFs for the vision
  calls; reused when retrying failed extractions.
- `artifacts/llm/extractions/model_output_GPT4-o`: JSON outputs from the LLM.
- `artifacts/llm/extractions/extracted_data.json`: Aggregated extraction result
  generated by `extraction_with_GPT_PDF.py`.
- `artifacts/llm/model_output_score`: Quality scores produced by the PDF
  pre-filter.
- `artifacts/datasets`: Consolidated CSV exports (`extracted_reactions.csv` and
  historical snapshots).
- `artifacts/logs/token_stats.json`: Token accounting for LLM calls.
- `archive/evaluations/llm_comparison`: Legacy benchmarking runs, now grouped
  into `scripts`, `data`, `artifacts`, `analysis`, `results`, and `reports` (see
  the local README for details).
- `archive/legacy`: Legacy helper scripts and artefacts kept for reference.

### Running the pipeline

```bash
python data_extraction/obtain_data.py
```

To enable additional steps import the helpers and pass custom flags:

```python
from data_extraction.obtain_data import ExtractionConfig, ExtractionSteps, obtain_data

config = ExtractionConfig(...)
steps = ExtractionSteps(crossref_search=True, pre_download_filter=True, extraction=True)
obtain_data(config, steps)
```

`ExtractionConfig` uses `pathlib.Path`, so absolute and relative paths work
equally well.

### Key modules

- `src/copolextractor/crossref_search.py`: aggregates DOIs and metadata.
- `src/copolextractor/predownloadfilter`: keyword- and embedding-based filtering.
- `src/copolextractor/PDF_download.py`: downloads the identified publications.
- `src/copolextractor/preextractionfilter`: optional PDF quality checks.
- `src/copolextractor/extraction_with_GPT_PDF.py`: LLM-driven extraction of
  reaction data.
- `src/copolextractor/data_into_csv.py`: consolidates the final data into
  `extracted_reactions.csv`.

See the respective modules for configuration specifics and advanced usage.
