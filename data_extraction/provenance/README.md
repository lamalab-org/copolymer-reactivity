# `data_extraction/provenance/` — historical run artefacts

This directory holds the **intermediate artefacts of the extraction run** that produced the `extracted_reactions.csv` underlying the paper's dataset. Nothing in the active pipeline reads from here at runtime; it's kept solely so the path from "Crossref query" to "row in `processed_data.csv`" is auditable.

The active pipeline (`data_extraction/obtain_data.py`) writes new runs under a configurable `ExtractionConfig` layout — see [`../README.md`](../README.md). The files here are the outputs of the specific run that produced the paper-cited dataset; they are not regenerated by ordinary use.

## What's here

| File / directory | Size | Step | What it contains |
|---|---:|---|---|
| `embeddings/embedded_papers.json` | ~97 MB | Pre-download filter | OpenAI embeddings of Crossref title + abstract; used by `src/copolextractor/predownloadfilter/embedding_filter.py` to score relevance before paying to download the PDF |
| `scored_doi.json` | ~41 MB | Pre-download filter | DOI → relevance-score map (initial 300k-record Crossref sweep narrowed to 1,851 download candidates) |
| `paper_list.json` | ~3 MB | Pre-download filter | XGBoost-filtered DOI list that proceeded to PDF download |
| `selected_200_papers.json` | ~600 KB | Pre-extraction filter | Manually-screened subset used for evaluation harness comparison |
| `copol_database/` | ~6 MB | Pre-extraction filter | Auxiliary copol-database lookups used during scoring |
| `model_output_score/` | ~7 MB | Pre-extraction filter | LLM-based PDF quality scores (gate on whether to extract) |
| `failed_crossref.json` | ~10 KB | Crossref search | DOIs that returned 404 / errored — recorded for audit |
| `journals.json` | ~19 KB | Crossref search | Per-journal hit counts (used for the keyword-scoring weights) |
| `error_log.txt` | ~8 KB | (all steps) | Pipeline error log from the run |

## Re-running the extraction

Nothing here needs to be present for an *active* extraction run — `obtain_data.py` will recreate whatever its `ExtractionConfig` specifies. Keep this directory if you want to:

- Audit *which* Crossref records were scored, embedded, or rejected.
- Reproduce the paper's selection exactly without paying for embeddings + LLM calls again.
- Spot-check the LLM extraction quality scores per paper.

If you wipe and re-run from scratch, expect different file paths and possibly a slightly different DOI selection (Crossref changes over time, LLM scoring is stochastic).

## What's *not* here

The actual extracted reactions live at `src/copolextractor/extracted_reactions.csv` (~5 MB, 4,976 rows). That's the file the downstream `copol_prediction/` pipeline ingests via `load_and_preprocess_data` to produce `copol_prediction/processed_data.csv`.
