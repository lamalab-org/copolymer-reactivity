# Archive

This directory contains old scripts and helpers that are no longer actively used but kept for reference.

## Files

- **add_morgan_to_splits.py**: Early attempt to add Morgan fingerprints to data splits
- **prepare_final_splits_with_morgan.py**: Alternative Morgan fingerprint preparation script
- **compare_results.py**: Initial results comparison script (superseded by feature_comparison/comparison/compare.py)
- **create_data_split.py**: Old data splitting script (superseded by create_train_test_split.py)

These files are kept for historical reference but are not part of the current workflow.
